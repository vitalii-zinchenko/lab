# Plan: Scaffold UI Service

## Context

The project has a Go API server with a full OpenAPI spec (`services/server/cmd/server/openapi.gen.json`). We want to add a frontend `services/ui` app that provides a visual interface for the API, with full type-safety derived from the existing spec. The UI needs to be wired into Tilt so it starts alongside the rest of the local dev environment.

---

## Tech Stack

| Concern | Choice | Reason |
|---|---|---|
| Framework | React 18 + TypeScript (Vite) | Fast DX, standard |
| Routing | `@tanstack/react-router` | File-based, type-safe routes |
| Server state | `@tanstack/react-query` | Cache, loading, error states |
| API client + hooks | **`orval`** | Generates typed hooks from OpenAPI spec automatically |
| UI components | `shadcn/ui` (Radix + Tailwind) | shadcn is a component collection, not a library — copied into repo |
| Dev server port | `5173` (Vite default) | |

> **`orval`** reads `services/server/cmd/server/openapi.gen.json` and emits typed fetch functions + TanStack Query hooks into `src/api/generated/`. Re-run `npm run codegen` whenever the spec changes.

### Modified: `Tiltfile`

Add a `local_resource` for the UI dev server after the existing services block:

```python
local_resource(
    'ui',
    serve_cmd='npm run dev --prefix services/ui',
    deps=['services/ui/src', 'services/ui/orval.config.ts'],
    resource_deps=['server'],
    labels=['services'],
    links=[link('http://localhost:5173', 'UI')],
)
```

## Implementation Steps

1. **Init Vite app** in `services/ui/` — `npm create vite@latest ui -- --template react-ts`
2. **Install deps**:
   - `@tanstack/react-router`, `@tanstack/router-devtools`
   - `@tanstack/react-query`, `@tanstack/react-query-devtools`
   - `orval` (dev), `axios` or `fetch` adapter
   - `tailwindcss`, `postcss`, `autoprefixer`
   - `class-variance-authority`, `clsx`, `tailwind-merge`, `lucide-react` (shadcn peer deps)
3. **Configure Tailwind** + `components.json` for shadcn
4. **Init shadcn/ui**: add initial components (`Button`, `Table`, `Card`, `Badge`, `Input`)
5. **Configure orval** (`orval.config.ts`):
   - Input: `../../server/cmd/server/openapi.gen.json`
   - Output mode: `@tanstack/react-query`
   - Output dir: `src/api/generated/`
6. **Run codegen**: `npm run codegen` → generates typed hooks (e.g. `useGetItems`, `usePostItems`, `useGetUsage`)
7. **Configure TanStack Router** — file-based routing via Vite plugin
8. **Add `npm run codegen` script** to package.json: `orval --config orval.config.ts`
9. **Wire up app** — `main.tsx` with `QueryClientProvider` + `RouterProvider`
10. **Implement routes** using generated hooks + shadcn components:
    - `/` — dashboard: items count, usage summary cards
    - `/items` — table + create form
    - `/events` — log table
    - `/usage` — usage table + stats
11. **Configure Vite proxy** so `/api/*` forwards to `http://localhost:8080` (avoids CORS in dev)
12. **Update Tiltfile** with the `ui` local_resource
